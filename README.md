# Hyperware Engine

Simple 2D Game Engine using C++

This engine was originally made for one of my university projects using PyGame at first, but later ported to C++ for better performance.

The engine is still heavily a work in progress and is incredibly barebones in nature. Some of the code isn't even done by me and will be replaced/updated later down the line. The goal is to slowly iterate over it until it becomes ready for use in game development.
